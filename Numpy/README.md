# NumPy Image Filters Project

A beginner-friendly image processing project built using only NumPy-based operations for learning real image manipulation fundamentals.

---

# Features

- Load images
- Convert to grayscale
- Negative filter
- Brightness adjustment
- Save processed images
- Modular project structure
- NumPy-based image processing

---

# Technologies Used

- Python
- NumPy
- Pillow
- Matplotlib

---

# Implemented Filters
1. Grayscale
Converts RGB image to grayscale using:

Gray=0.299R+0.587G+0.114B

2. Negative Filter
Creates image negative:

NewPixel=255−OldPixel

3. Brightness Adjustment
Increases brightness:

NewPixel=OldPixel+Value
